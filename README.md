## About Me

I’m Abu Bin Fahd, a **Data Scientist and AI Engineer** interested in turning messy data and promising models into useful, dependable products. I work across the machine learning lifecycle: exploring data, building and evaluating models, and developing the services and workflows that put them to use.

```yaml
name: Abu Bin Fahd
roles:
  - Data Scientist
  - AI Engineer
interests:
  - Data analysis, statistics, and machine learning
  - Deep learning, NLP, and computer vision
  - Large language models, RAG, and AI agents
  - Model evaluation, deployment, and MLOps
currently_exploring:
  - Retrieval-augmented generation
  - Multimodal AI
  - Production-ready ML workflows
open_to: Collaboration on data science and AI projects
```

## What I Work On

- **Data science:** data cleaning, exploratory analysis, feature engineering, statistical reasoning, and model evaluation.
- **Machine learning:** classification, regression, recommendation, and deep learning with practical evaluation workflows.
- **Generative AI:** LLM applications, prompt and retrieval workflows, embeddings, RAG, and tool-using agents.
- **Computer vision and NLP:** experimentation with image, text, and multimodal tasks.
- **ML engineering:** APIs, reproducible pipelines, model tracking, containers, and deployment foundations.
